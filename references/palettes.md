# 配色速查（Okabe-Ito / Paul Tol / Wong）

> 画科研论文图件时，配色必须同时满足**色盲安全**、**灰度可读**、**最终尺寸下字号合规**。
> 尺寸与字号规则见 `references/journal-figure-standards.md`；本文件只管颜色。

## 一、三条硬规则

1. **≤3 个色相 + 灰阶**，背景白或近白。超过 3 个色相，读者开始靠猜。
2. **有大小/多少之分 → 单色相递进**（同一色相由浅到深）；**只是类别区分 → 分类色 + 形状/标记二次编码**（不能只靠颜色）。
3. **注释、连线、箭头用中性灰**——它们的信息量低于数据本身，不能比数据更亮。

补充两条期刊硬约束（Nature）：
4. **不要彩色文字**：图例与正文用「色块 + 黑色文字」，不要用蓝字/红字区分语义。
5. **颜色不能是唯一通道**：必须在形状、线型或直接标注上做冗余编码。

## 二、六套即用色板（HEX 直接可用）

### A. Okabe-Ito（定性 8 色，色觉障碍安全首选）

来源：Okabe & Ito 原版 Color Universal Design 手册；Bang Wong 2011 在 *Nature Methods* 推广其 7 色子集（去掉黑色）。
**Nature 图件规范直接点名这一套。**

| 名称 | HEX | RGB | 建议用途 |
|---|---|---|---|
| 黑色 | `#000000` | 0,0,0 | 参考线、零假设、主数据系列 |
| 橙色 | `#E69F00` | 230,159,0 | 第二系列；与蓝形成最强对比 |
| 天蓝 | `#56B4E9` | 86,180,233 | 第三系列；辨识度极高 |
| 蓝绿 | `#009E73` | 0,158,115 | 第四系列 |
| 黄色 | `#F0E442` | 240,228,66 | 只作填充（细线不可见），需加深色描边 |
| 蓝色 | `#0072B2` | 0,114,178 | 强调色；与橙配对最佳 |
| 朱红 | `#D55E00` | 213,94,0 | 误差棒、重点标注 |
| 红紫 | `#CC79A7` | 204,121,167 | 第八类别上限 |

分配顺序建议：橙 → 天蓝 → 蓝 → 朱红 → 蓝绿 → 黄 → 红紫，黑色留给参考线。
**类别 > 6–8 个时不要靠颜色**，拆子图或加形状编码。

### B. Paul Tol Bright（定性 7 色）

`#4477AA` `#66CCEE` `#228833` `#CCBB44` `#EE6677` `#AA3377` `#BBBBBB`
折线/散点，白底对比好。另有 **Tol Muted（10 色）** 用于 9–10 类。

### C. Nature/Cell 低饱和 5 色（定性 5 色）

`#4E79A7` `#F28E2B` `#E15759` `#76B7B2` `#59A14F`
顶刊柱状/箱线风格，视觉刺激小。**含红绿对，色盲友好弱于 Okabe-Ito**，仅在需要匹配目标期刊既有图件时用。

### D. 连续色板（顺序型数据、热图）

- **Viridis**：`#440154` → `#31688E` → `#35B779` → `#90D743` → `#FDE725`
- **Cividis**（专为绿色盲优化）：`#00204C` → `#003A70` → `#575D6D` → `#A49C5A` → `#FFEA46`
- **Plasma**（保证彩印）：`#0D0887` → `#7E03A8` → `#CC4778` → `#F89540` → `#F0F921`

连续数据必须感知均匀；Okabe-Ito 是**分类**色板，不可用于连续映射。

### E. 发散色板（中点有意义的变量）

- **RdBu**：`#B2182B` ↔ `#F7F7F7` ↔ `#2166AC`
- **PRGn**（色盲更友好）：`#762A83` ↔ `#F7F7F7` ↔ `#1B7837`——优先于 RdBu 用于无障碍场景

### F. 灰度 / 单色印刷版

`#EDEDED` `#A6A6A6` `#333333` + 图案/形状区分。期刊黑白版时用这套。

## 三、Visio 落地：单色递进与语义映射

### 3.1 单色递进（有序变量：开启项数、强度、等级）

| 档 | 填充 | 边框 | 文字 |
|---|---|---|---|
| 浅（0 项 / 低） | `#EAF2F7` | `#B0C7D6` | `#1A1A1A` |
| 中（1 项 / 中） | `#B7D5E5` | `#0072B2` | `#1A1A1A` |
| 深（2 项 / 高） | `#0072B2` | `#0072B2` | `#FFFFFF` |

灰度亮度 0.94 → 0.82 → 0.35 有序，黑白打印仍可区分。

### 3.2 按任务场景的即用配方

按"我要画什么"直接抄，而不是先选色板再挑色：

| 场景 | 色值 | 规则 |
|---|---|---|
| **双色对比**（实验组 vs 基线 / 现状 vs 目标） | 主 `#0072B2` / 对照 `#E69F00` / 中性 `#9AA5AD` | 三色封顶，正好卡在「≤3 色相 + 灰」的上限内 |
| **分类 5 色**（无序类别 ≤5） | `#0072B2` `#E69F00` `#009E73` `#CC79A7` `#56B4E9` | 取自 Okabe-Ito 子集；类别 >5 改用 §二 的其它色板 |
| **状态三色**（正常 / 注意 / 风险） | `#009E73` / `#E69F00` / `#D55E00` | **必须配图标或形状做二次编码**，不能只靠颜色区分 |
| **灰度 / 单色印刷**（期刊黑白版） | `#EDEDED` `#A6A6A6` `#333333` + 图案填充 | 同 §二 F 组 |

### 3.3 形状语义 → 颜色

| 形状角色 | 填充 | 边框 | 文字 |
|---|---|---|---|
| 基线 / 背景形状 | 最浅一档 | 同色系 20% | `#1A1A1A` |
| 被强调的主要对象 | 主色 | 主色 | `#FFFFFF` |
| 次要对象 | 中间档 | 主色 60% | `#1A1A1A` |
| 判定点 / 风险 | 不填色，只加边框 + 图标 | 状态色 | `#1A1A1A` |
| 注释 / 容器 | 无填充 | 灰 `#C9D3DA` 0.75 pt | 灰 `#6B7882` |
| 连线 / 箭头 | — | 灰 0.75 pt（强调 1.5 pt） | — |

### 3.4 Visio 特有的两个坑

1. **主题色 vs 固定 RGB**：用主题色填充的形状，换主题或对方打开时会整体变色。**交付件一律用固定 RGB**（ShapeSheet 只认 `RGB(r,g,b)` / `HSL()` 函数，**不认 `#RRGGBB`**），别用主题色。
2. **深色卡上的标记改白色**：蓝底上画蓝圈等于没画；深卡上的「开启」标记一律白色实心点，并在图例里注明。

### 3.5 文字颜色的额外约束

- 期刊图件**不用彩色文字**：`评估目的：` 这类说明行一律用 `#1A1A1A`，颜色只留在卡片填充、边框、图例色块上。
- 深色卡片上的文字用白色/浅色（`#EEF5F9`），这是高对比反白，不是「彩色文字」。
- 状态色（绿/橙/红）只用于**形状与标记**，不要拿去写字。

## 四、投稿前自检（必做两步）

1. **灰度测试**：全图去饱和（Visio：改页面主题色为灰阶，或用图片工具转灰）。
   每个类别仍凭亮度区分 → 通过。
2. **CVD 模拟**：用 [Coblis](https://color-blindness.com/) 或 Color Oracle / Sim Daltonism 分别模拟
   红色盲、绿色盲、蓝黄色盲，确认没有只靠红绿区分的编码。

常见错误：加棕色（不在 Okabe-Ito 集内，对绿色盲易与深橙混淆）、用透明度叠加（混合色未验证）、
黄色画细线、红绿做发散色板两端、同一变量在不同子图换色板、类别超过 8 个仍只靠颜色。

详见 `references/journal-figure-standards.md`。
