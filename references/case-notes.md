## 1. 2×3 蛇形流水线的实测参数

> 用途：把「一排 6 个等宽竖框」改成 2×3 蛇形（上排向右、下排向左）。

```
列：margin 0.19 + 卡宽 4.091 + 列距 0.34 ×2  →  0.19 / 4.621 / 9.052 … 13.143
行：上排 4.46–7.20，下排 1.38–4.12，行距 0.34；底部公式条 0.20–1.04
卡内：标题 16 pt（徽标 0.46 + 间隙 0.16）→ 副标题 10.5 pt → 内容区 2.06 in
```

- 页高从 6.667 涨到 7.40 in → 183 mm 宽的期刊件变成 **183 × 101.6 mm**，仍是好版面。
- 蛇形下排箭头**方向朝左**（`New-VisioArrow -X1 <右卡左缘> -X2 <左卡右缘>`），编号 1…6 保持递增即可自证流向。

## 2. 立体感的形状叠层配方（三层）

> Visio 没有阴影 / 渐变 / 透明单元格，立体感只能靠叠层造。

| 层 | 画法 | 目的 |
|---|---|---|
| 投影层 | 圆角矩形，浅灰 `RGB(226,232,238)`，无描边，偏移 (+0.10, −0.10) | 悬浮感 |
| 侧面层 | 同形，主色**深一档**（×0.78），无描边，偏移 (+0.05, −0.05) | 板块厚度（露在右下沿） |
| 正面层 | 真正的那张卡 | 主体 |

- 图标徽标用同样三层，再加一条**顶部高光带**（主色亮 10%）假扮渐变；高光带别做太亮（≥1.15 倍会像贴纸）。
- 偏移量小 = 薄板感，大 = 厚板感；0.05 in（母版 13.333 in）比较克制。
- 形状总数会翻 2–3 倍（6 卡流水线 ≈ 208 个形状），Visio 扛得住。

## 3. 一个完整分工示例（2×2 对照矩阵）

卡片 = BASIC 矩形（圆角 0.13 in）、开关状态 = BASIC 圆形（实心/空心）、
坐标轴 = ARROWS 普通双箭头、注释 = ANNOT 圆形标注、最终形态标记 = BASIC 菱形，
对照箭头 = 线 + 实心箭头端。**3 个模具族、5 个母版、2 类原生图元。**

> 注意：纯圆点用 `BASIC_M`「圆形」，**不要用 `MATRIXDOT_M`**——它自带编号徽标。
