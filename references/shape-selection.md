## 1. 模具大类概览

362 个模具里，通用绘图件只有约 50 个（图形元件/箭头/图例、流程与工作流、数据矩阵图表三类），
其余 300 多个是行业图标。**做研究示意图只用通用那批就够，不必翻遍全库**——分类明细见 `stencil-catalog.md` 第 8 节。

## 3. 细分形状怎么选

### 3.1 箭头：五个模具族的定位（共 141 个箭头类形状）

| 模具 | 数量 | 本质 | 什么时候用 |
|---|---:|---|---|
| **ARROWS_M** | 28 | 独立示意箭头：普通箭头、现代箭头、圆角右箭头、弧形箭头、环形箭头、十字/丁字箭头、燕尾/虚尾箭头、多行箭头 | 需要"看得见的方向感"，且不跟随形状移动 |
| **ARROWS2_M** | 16 | 「线轮廓」「轮廓」两套 × 8 种走线（直线、轻弯、左右旋转、U 形弯） | 要空心描边箭头做强调，或需要 U 形回环 |
| **BLOCK_M** | 41 | 块状/开放式箭头 + 一维二维 + **树枝连接**（双树枝直角/斜角、多树枝斜角）+ 动态连接线 | 架构图的正交走线、一对多分支汇聚 |
| **BLOCK3_M** | 19 | 单色块箭头（左/右/上/下/左右/上下）+ 肘形 1–4 + 框架 | 最省事的方向强调；**填充色可直接改** |
| **MATRIXDOT_M** | 37 | 标记点：点 1–4、菱形 1–5、三角/圆角三角、箭头 1–11、固定/Pin 1–6、星形、标志、交叉 | 在矩阵、地图、平面图上标"位置/优先级/状态" |

### 3.2 箭头决策表（按你要表达的意思选）

| 想表达 | 首选 | 次选 | 别用 |
|---|---|---|---|
| 步骤之间的走向（会频繁改布局） | 动态连接线（BASFLO_M / CONNEC_M） | 单箭头（BLOCK_M） | 手绘直线 |
| 强调因果、力量感 | 块状单箭头（ARROWS_M） | 单箭头（BLOCK_M） | — |
| 双向 / 互为前提 | 普通双箭头（ARROWS_M）、左/右箭头（BLOCK3_M） | 双箭头线 | — |
| 阶段递进 1→2→3→4 | PROCESS_M「箭头步骤」「3 步箭头流程」 | V 形步骤 | 四个互不相连的箭头 |
| 循环 / 反馈回路 | 环形箭头、弧线箭头、手杖形箭头（ARROWS_M） | 右弧形箭头 | 几段直线硬拼 |
| 正交走线（架构、组织） | 双树枝直角（BLOCK_M） | 肘形 1–4（BLOCK3_M） | 斜线交叉 |
| 一对多分发 | 多树枝直角（BLOCK_M） | 多个单箭头 | — |
| 弱关系 / 可选路径 | 虚线（ARROWS_M）+ 0.75pt | 线轮廓（轻微弯曲） | 实心粗箭头 |
| 跨页 / 跨系统跳转 | 跨页引用（BASFLO_M）+ 跨页连接线 | — | 一根横穿全图的长线 |
| 标注尺寸 / 间隔 | 信息线（ANNOT_M） | — | 普通箭头 |
| 视觉上要"轻"的次要强调 | 虚尾箭头、燕尾形箭头 | 开放/闭合条（BLOCK_M） | 纯实心块箭头 |

**注意**：燕尾 / 虚尾箭头在本库中没有强制语义（工程制图里"燕尾"才表示起点），只作视觉轻重区分，不要当标准符号用。

### 3.3 箭头的四条统一规则

1. **一张图只用一种箭头样式**；混用两种以上，读者会以为语义不同。
2. **线宽只有两档**：结构线 0.75 pt、强调线 1.5 pt。箭头端大小固定（`EndArrowSize = 2`），不要有的粗有的细。
3. **关系用连接线，装饰才用块箭头**：块箭头不绑定形状，一拖就错位；连接线（动态连接线）会自动跟随。
4. **箭头不要穿文字**：需要跨越时用信息线或折线绕行。

### 3.4 流程形状（BASFLO_M 15 个）

| 形状 | 语义 | 使用约束 |
|---|---|---|
| 开始/结束 | 起止 | 全图 1 个起点、1–2 个终点；用圆角矩形或椭圆 |
| 流程 | 动作 / 步骤 | 一律用动词短语（"校验令牌"而不是"令牌校验"） |
| 判定 | 条件分支 | 二元出口；三路以上就拆成两个判定，别让一个菱形挂四条线 |
| 子流程 | 折叠的细节 | 双击进子页画，主图保持一层 |
| 数据 | 输入 / 输出 | 不要用矩形代替 |
| 文档 | 报表 / 文件产物 | 与"数据"区分：文档是交付物，数据是流 |
| 数据库 | 持久存储 | 圆柱只表示存储，不表示服务 |
| 外部数据 | 外部系统输入 | 用于划清系统边界 |
| 页面内引用 / 跨页引用 | 跳转点 | 交叉线超过 3 条就改用引用，而不是硬连 |

### 3.5 标记形状（MATRIXDOT_M 37 个）

- **点 1–4**：中性数据点，无褒贬，最安全
- **菱形 1–5**：强调"关键项 / 最优解"
- **三角 / 圆角三角**：表示增量方向（改善 / 恶化）
- **箭头 1–11**：方向性注释，尺寸比连线箭头小，注意别和连线混淆
- **固定 / Pin 1–6**：在地图、平面图上锚定位置
- **标志 / 星形 1–4**：达标、推荐、重点关注

规则：**一张图 ≤3 种标记**，每种标记只承载一个变量；标记必须有图例说明。

## 6. 跨模具混用（避免单一模具打天下）

### 6.1 混用的正确姿势：按"角色"分工，不按"好不好看"

一张图里 4 个角色，各找一个模具族承担，**同一角色不要用两个族**：

| 角色 | 职责 | 推荐模具 |
|---|---|---|
| 容器 | 分组、分区、卡片底板 | BASIC_M（矩形 + Rounding 圆角） |
| 语义形状 | 形状本身就带含义（判定、存储、步骤） | BASFLO_M、PROCESS_M、VENNDIAG_M、PYRAMID_SHAPES_M |
| 连接 / 指向 | 关系与方向 | ARROWS_M（双箭头 / 弧线）、BLOCK_M（正交树枝）、CONNEC_M（动态连接线） |
| 标记 / 标注 | 点出重点、加一句解释 | `BASIC_M` 圆形 / 菱形（纯标记），`ANNOT_M`（圆形标注 / 信息线）。**别用 `MATRIXDOT_M`**——它自带编号徽标 |
| 图例 | 解释颜色与符号 | LGND_M / LEGEND_M |

一个完整分工示例（卡片 = BASIC 矩形（圆角 0.13 in）、开关状态 = BASIC 圆形（实心/空心）、
坐标轴 = ARROWS 普通双箭头、注释 = ANNOT 圆形标注、最终形态标记 = BASIC 菱形，
对照箭头 = 线 + 实心箭头端。**3 个模具族、5 个母版、2 类原生图元**）见 `case-notes.md` §3。



### 6.2 三条纪律

1. **角色不重叠**：容器不再兼任"语义"（别用判定菱形当卡片）。
2. **样式必须统一**：圆角半径、线宽（0.75 / 1.5 pt）、字号（9.5 / 12 / 15 pt）三件事跨模具保持一致——混用模具的视觉统一来自样式，不来自形状本身。
3. **同族只取 1–2 个母版**：ARROWS_M 有 28 个箭头，一张图挑 1 种就够；挑两种会让读者以为语义不同。

### 6.3 实测踩到的四个坑（本机 Visio 16.0）

| 现象 | 原因 | 对策 |
|---|---|---|
| MATRIXDOT 的点 / 菱形拖出来带黄色数字徽标和"在此处输入文本" | 它们是为矩阵图设计的**带标签数据点**，不是纯图形 | 要纯圆点用 BASIC_M 圆形；要编号点才用 MATRIXDOT |
| PROCESS「V 形步骤」「箭头步骤」设了 2.7×0.32 还是显示成大色块 | 母版宽高被 guard 锁定 | 改用 BASIC 矩形 + 文本，或接受母版默认尺寸 |
| ARROWS「普通箭头」设 `Angle=180` / `FlipX=1` 都不转向 | 单向箭头母版方向锁死 | 反向箭头用"线 + 实心箭头端"，或改用「普通双箭头」 |
| 块箭头（BLOCK3_M）父形状填色无效 | 组形状，子形状各带样式 | 递归 `Shapes` 逐个上色，或直接用单色块箭头 |

**通用规避**：凡是"母版本身有预设语义"的形状（数据点、流程步骤条、单向箭头），
自动化改尺寸和方向都可能被 guard 挡住。做**成稿级**图件时，容器与箭头用图元 + 少量语义母版，
比全用母版更可控；做**草稿**时全用母版更快。

### 6.4 一张图该混几个模具

- **2 个族**：太单薄，通常只有一个语义维度（如纯流程图）
信息层次清楚的常规区间（`case-notes.md` §3 的示例用 3 个）
- **6 个以上**：读者开始数形状而不是读内容，除非是仪表盘式的信息图

配套样张：跑 `scripts/shape-sheet.ps1` 生成 `out/shape-sheet.png`（本机 6 个模具、**21** 个候选形状的真实外观）。
